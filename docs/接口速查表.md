# 动物园综合管理系统——统一接口速查表

> 用途：三人开发、联调、合并时统一接口与公共规则。  
> 标记：A = 动物与健康；B = 饲养与物资；C = 游客与票务；共同 = 三人共同维护。

---

## 1. 三人分工总表

| 同学 | 子系统         | 主要负责内容                                         | 主要数据文件                                                |
| ---- | -------------- | ---------------------------------------------------- | ----------------------------------------------------------- |
| A    | 动物与健康管理 | 动物档案、园区、动物状态、体检、疾病、治疗、康复     | `animals.txt`、`zones.txt`、`medical_records.txt`           |
| B    | 饲养与物资管理 | 食物库存、喂养计划、喂养记录、库存预警               | `foods.txt`、`feeding_plans.txt`、`feeding_records.txt`     |
| C    | 游客与票务服务 | 游客账号、购票、退票、检票、订单、评价、游客查询动物 | `visitors.txt`、`orders.txt`、`tickets.txt`、`feedback.txt` |
| 共同 | 公共层         | `main.cpp`、公共输入校验、日志、统一菜单规则         | `operation_logs.txt`                                        |

# 3. A 同学公共数据结构

| 名称                     | 负责人 | 谁使用  | 内容                   |
| ------------------------ | ------ | ------- | ---------------------- |
| `AnimalStatus`           | A      | A、B、C | 统一动物状态           |
| `AnimalBasicInfo`        | A      | A、B、C | 跨模块只读动物基本信息 |
| `ZoneInfo`               | A      | A、C    | 跨模块园区信息         |
| `animalStatusToString()` | A      | A、B、C | 动物状态转显示文字     |

### `AnimalStatus`

| 枚举值        | 中文   | B：允许喂养 | C：游客展出 |
| ------------- | ------ | ----------: | ----------: |
| `NORMAL`      | 正常   |          是 |          是 |
| `TREATMENT`   | 治疗中 |          是 |          否 |
| `ISOLATED`    | 隔离   |          是 |          否 |
| `TRANSFERRED` | 已转出 |          否 |          否 |
| `DECEASED`    | 已死亡 |          否 |          否 |

### `AnimalBasicInfo`

| 字段        | 类型           | 含义                         |
| ----------- | -------------- | ---------------------------- |
| `animalId`  | `string`       | 动物唯一编号                 |
| `name`      | `string`       | 动物名称                     |
| `category`  | `string`       | 类别，如 Mammal/Bird/Reptile |
| `species`   | `string`       | 物种                         |
| `zoneId`    | `string`       | 园区编号                     |
| `zoneName`  | `string`       | 园区名称                     |
| `status`    | `AnimalStatus` | 当前状态                     |
| `onDisplay` | `bool`         | 是否展出                     |

# 7. 全局统一规则

| 项目           | 统一规则                                | 负责人 |
| -------------- | --------------------------------------- | ------ |
| 文件字段分隔符 | `|`                                     | 共同   |
| 日期格式       | `YYYY-MM-DD`                            | 共同   |
| 时间格式       | `HH:MM`                                 | 共同   |
| 完整时间格式   | `YYYY-MM-DD HH:MM:SS`                   | 共同   |
| 菜单返回       | `0 = 返回上一页`                        | 共同   |
| 菜单返回       | `M = 返回主菜单`                        | 共同   |
| 菜单返回       | `Q = 退出系统`                          | 共同   |
| 普通修改类接口 | 成功 `true`，失败 `false`               | 共同   |
| 多条查询结果   | `vector<T>`                             | 共同   |
| 单条查询结果   | `bool + out参数`                        | 共同   |
| 跨模块查询接口 | 尽量加 `const`                          | 共同   |
| 文本字段       | 不能包含 `|`、`\r`、`\n`                | 共同   |
| ID 字段        | 不能为空、不能包含空白、不能包含 `|`    | 共同   |
| 数据修改       | 各子系统只修改自己负责的数据文件        | 共同   |
| 跨模块数据     | 通过 Manager 接口访问，不直接读对方文件 | 共同   |

# 18. 三人开发时最重要的约定

| 规则                     | 说明                                             |
| ------------------------ | ------------------------------------------------ |
| A 不依赖 B               | `AnimalManager` 不 `#include "FeedingManager.h"` |
| B 可以依赖 A             | B 通过 `const AnimalManager&` 查询动物           |
| C 可以依赖 A             | C 通过 A 的查询接口显示动物和园区                |
| B/C 不直接修改 A 数据    | 不直接写 `animals.txt`                           |
| A 不修改 B 数据          | 不直接写 `feeding_plans.txt`、`foods.txt`        |
| A 不修改 C 数据          | 不直接写订单和门票                               |
| `main.cpp` 不写具体业务  | 只负责创建、加载、菜单跳转、保存                 |
| 公共接口改名必须三人同步 | 避免接口对不上                                   |

# 20. 一句话分工

| 同学 | 一句话                                           |
| ---- | ------------------------------------------------ |
| A    | 管“动物是谁、在哪里、什么状态、健康情况如何”     |

| C    | 管“游客怎么注册、买票、入园、查询动物、提交反馈” |
